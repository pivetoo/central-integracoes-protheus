# central-integracoes

Tela clássica ADVPL no Protheus que conecta a categoria → provedor → credencial da
[IntegrationPlatform](https://github.com/pivetoo) diretamente do ERP, sem duplicar
credenciais no Protheus. Fundação reutilizável por qualquer automação futura (a
primeira delas: Régua de Cobrança Inteligente, projeto irmão).

Spec de design em [docs/superpowers/specs/2026-08-17-central-integracoes-design.md](docs/superpowers/specs/2026-08-17-central-integracoes-design.md).
